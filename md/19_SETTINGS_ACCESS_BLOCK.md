# ✅ План: Блок “Доступ и Telegram” в /settings

**Дата:** 2026-01-18  
**Цель:** дать администратору возможность менять TG ID, токен бота и название компании после регистрации.

---

## 1) Backend

- Новый endpoint: `GET /api/settings/company`
- Новый endpoint: `PATCH /api/settings/company`
- Валидация:
  - `admin_telegram_id` > 0
  - `telegram_bot_token` валиден через Telegram `getMe`
  - токен уникален (не используется другой компанией)
  - `name` >= 3 символов

---

## 2) Frontend

- Новый блок “🔑 Доступ и Telegram” в `/settings`
  - Логин (email) — read‑only
  - TG ID администратора — редактирование
  - Токен бота — редактирование
  - Название компании — редактирование
  - Кнопка “Сохранить”

---

## 3) Критерий готовности

- Админ может изменить TG ID и токен бота без обращения к БД.
- Новые значения сохраняются и отображаются при повторном входе.
