# Упрощенная регистрация через @barber76_bot

## Цель
Добавить в @barber76_bot кнопку «📝 Регистрация» и упрощенный сценарий создания компании,
который запрашивает только Telegram ID администратора, email и телефон. Остальные данные
заполняются позже в настройках веб‑панели.

## Область изменений
- Backend: новый публичный endpoint `/api/public/companies/register-lite`.
- Backend: новая схема `CompanyRegistrationLite`.
- Bot: новый FSM-скрипт регистрации в `@barber76_bot`.
- Bot: новая кнопка меню в `@barber76_bot`.

## Поток данных
1. Пользователь нажимает «📝 Регистрация» в @barber76_bot.
2. Бот запрашивает Telegram ID администратора, email и телефон.
3. Бот вызывает `/api/public/companies/register-lite`.
4. Backend создает компанию (без Юкассы), возвращает `login_email` и `password`.
5. Бот показывает логин/пароль пользователю и отправляет их на указанный TG ID.

## Валидации
- Email: стандартная валидация EmailStr.
- Телефон: `+7XXXXXXXXXX`.
- Telegram ID: число > 0.

## Безопасность
- Пароль отправляется только в Telegram.
- Бот может писать пользователю только если тот уже нажал `/start`.

## Критерии готовности
- В @barber76_bot есть кнопка «📝 Регистрация».
- После регистрации бот показывает логин/пароль в чате.
- Бот отправляет логин/пароль на указанный Telegram ID.
- Компания создается без обязательного токена бота.
